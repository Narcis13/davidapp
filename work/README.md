# Gate messages for clips 7 and 8

Each folder holds the messages the session wrote at the `[me]` stops of the motion process, in order:
brief → script → style frames → transitions → animatic → final, with the frames it showed. **There is no owner
in this session: no gate was approved by one; the session wrote each message and went on.**

The process should come from `motion_prompt_fablecut.md`. That file was not in the repository when iteration 3
ran (see `PROGRESS.md`, Blocked), so these gates follow the process the iteration 3 brief describes, and the checks
are the ones the brief names (all measured by the studio's own tools). The calls are journalled in
`showcase/journal/<clip>.jsonl`, so `npm run showcase` rebuilds both clips.

- `clip-7-a-video-that-checks-itself/` — voiced explainer, 62 s, horizontal + vertical from one composition.
- `clip-8-cuvinte-pe-ritm/` — text and music for a feed (Reels), 38.4 s, vertical, Romanian, cut on the bars.
